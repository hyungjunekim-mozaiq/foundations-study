목차의 크기와 수업의 깊이를 혼동했다. 기존 수업은 다루겠다고 한 범위에 비해 설명과 예제가 부족했다. 이 문서는 무엇을 바꾸어야 하는지 검토한 제안이다. 전체 교육과정을 새로 완성했다는 뜻은 아니다.

현재 수업에서 부족했던 것

펌프 단원은 여덟 절로 나뉘어 있지만, 본문은 태그를 제외하면 약 1,800자다. 펌프 곡선은 이름과 교점만 등장하고 그림, 곡선을 읽는 과정, 계산의 출발점이 없다. 뒤에 추가한 절은 앞 설명을 반복하는 경우가 많다. 절 수를 늘린 것에 비해 새로 배울 내용은 적었다.

수질 단원도 “pH가 소독에 영향을 준다”를 말하지만, 산염기 평형과 염소의 화학종을 충분히 가르치지 않는다. 이 상태에서 측정값과 운영 지침을 읽으라고 하면, 배운 원리로 판단하기보다 또 다른 주의사항을 외우게 된다.

문제는 간단한 단위 변환, 목록 나열과 당연한 주의사항에 치우쳤다. 원리를 선택하거나, 틀린 설명을 반박하거나, 관찰에서 가설을 구분하는 문제는 부족했다. 복습 카드도 개념 사이의 관계를 재구성하는 연습으로는 충분하지 않았다.

교재를 읽으며 확인한 차이

OpenStax의 Bernoulli 단원은 압력에 의한 일과 에너지 변화에서 식을 유도한다. 식의 항을 설명하고 적용 예제로 이어간다. 수식이 등장한다는 사실보다, 왜 그 식을 쓸 수 있는지 연결하는 과정이 중요했다.

Chemistry 2e의 완충 용액 예제 14.20은 완충이 있는 용액과 없는 용액에 같은 변화가 생겼을 때를 비교한다. “완충은 pH 변화를 줄인다”라는 한 문장 대신, 대비되는 계산으로 그 뜻을 확인하게 한다.

MIT 운영관리의 Capacity 강의는 공정, 처리 능력, 혼잡, 의사결정 순으로 간다. 일정한 도착과 변동하는 도착을 구분하고, 연습문제에서 처리 능력과 서비스 시간을 바꾼다. 평균이 같아도 결과가 달라지는 조건을 공부하게 한다.

MIT 건축기술의 결로 강의는 물의 침입을 액체의 유입, 모세관 이동, 공기 누설, 수증기 확산으로 나눈다. “물기가 있다”라는 한 증상에서 어떤 메커니즘을 생각해야 하는지 분해한다.

위 자료의 해당 본문과 예제를 검토했다. 각 교재와 강좌 전체를 완독한 것은 아니다. 오래된 교재는 기본 원리의 근거로 사용하며 최신 기준의 근거로 사용하지 않는다. 수강이나 원문 완독을 학습자에게 과제로 넘기지 않는다.

학습 연구를 수업의 행동으로 바꾸기

  1. 이해력과 배경지식은 따로 본다. 수학에 익숙해도 수두, 완충능, 열교 같은 개념은 새로 배울 수 있다. 짧은 질문으로 막힌 개념을 확인하고 필요한 설명을 제공한다. 자기 설명을 요구하기 전에 설명할 재료가 있어야 한다. How People Learn II, 5장은 기존 지식이 학습을 돕기도, 편향을 만들기도 한다고 정리한다.
  2. 처음에는 풀이의 이유를 보여주고, 점차 직접 풀게 한다. 완성된 풀이 → 일부 단계 완성 → 독립 문제로 도움을 줄인다. 이번 시안은 같은 펌프 예제를 쓰되 마지막 문제에서 높이 차이를 추가했다. 예제와 문제를 번갈아 사용하는 구성은 IES 학습 지침의 근거를 참고했다.
  3. 읽은 내용을 다시 만들어 보게 한다. 본문을 가리고 관계를 설명하거나 그림을 그린다. 그 뒤 모범 설명과 비교한다. IES는 기억에서 꺼내는 연습과 시간 간격을 둔 학습을 권고한다. 정확히 며칠 간격이 개인에게 최선인지는 여기서 검증하지 않았다.
  4. 비슷하지만 다른 문제를 비교한다. 같은 증상에 원인이 다른 경우, 다른 시설에 같은 원리가 쓰이는 경우를 넣는다. 여러 분야를 소개하기만 하면 전이가 생긴다고 가정하지 않는다. Chi 등의 물리 문제 분류 연구에서 제시한 전문가와 초보자의 지식 조직 차이를 설계의 참고로 삼는다. 이 사이트가 전문성을 재현했다는 근거는 아니다.

이것들은 모든 문단을 퀴즈로 끊으라는 뜻이 아니다. 읽기 흐름을 유지하면서 중요한 관계가 바뀌는 지점에만 설명, 예측과 문제를 둔다. 선호하는 화면과 학습 효과도 구분한다. 이 설계가 실제로 잘 맞는지는 사용 후 확인해야 한다.

AI에게 묻는 과정도 수업에 포함한다

단어를 모르거나 설명이 끊기는 순간에는 바로 질문한다. 이때 AI가 정답을 숨긴 채 질문만 반복하면 불필요하게 막힌다. 개념 질문에는 직접 설명하고, 풀이 도움에는 현재 시도에서 막힌 부분을 찾아 힌트를 주는 방식이 적절하다는 것이 이번 설계 판단이다.

답변을 받은 뒤에는 그 설명을 다른 숫자나 조건으로 한 번 사용해 본다. 예컨대 “수두가 뭐야?”를 물었다면, 설명 후 “같은 수조로 돌아오는데 배관 최고점 높이를 더해야 할까?”를 확인한다. 질문 이력 전체를 복습하는 대신, 새로 알게 된 관계와 남은 의문을 저장한다.

Bastani 등의 2025년 고교 수학 무작위 실험에서는 일반적인 GPT 도움을 받은 집단이 도구 없는 시험에서 불리했고, 교사가 설계한 풀이 지원을 넣은 집단에서는 그 손해가 크게 줄었다. 후자가 무도구 시험에서 우월했다는 결과는 아니다. 성인 공학 학습에 같은 크기의 효과가 난다고 옮길 수 없지만, 도움받아 수행한 결과와 혼자 배운 것을 구분해야 한다는 근거다.

사이트는 현재 절, 가정, 내 풀이와 질문을 복사한다. AI는 기존 채팅에서 사용한다. 브라우저에서 질문 위치로 돌아올 수 있고 노트도 남는다. 사이트 내부 API나 계정 연결은 필요하지 않다.

선택한 구조: 과목별 목차와 통합 단원

A. 학문별 과정을 순서대로

물리 → 화학 → 건축과 설비 → 운영관리처럼 각 과목을 길게 이어간다. 개념의 체계는 선명하지만, 여러 과목이 하나의 시설에서 만나는 경험이 늦어질 수 있다.

B. 과목별 목차와 통합 단원을 함께 / 선택한 안

전체 목차는 학문별로 정리하고, 실제 학습 순서는 선수 관계에 맞춰 연결한다. 에너지와 흐름을 배운 뒤 순환 설비를 해석하고, 산염기와 반응을 배운 뒤 수처리를 해석한다. 운영과 확률은 별도의 흐름으로 병행한다. 각 통합 단원에서 여러 기초 개념을 다시 사용한다.

“지금 당장 업무에 써야 한다”는 숙제를 붙이지 않아도, 기초를 왜 배우는지와 어디까지 이어지는지를 볼 수 있다. 같은 개념이 여러 단원에 중복 등장할 때 기준 설명은 하나로 유지해야 한다.

C. 시설 하나를 끝까지

수영장의 구조, 유체, 화학, 가열, 제어와 운영을 깊게 공부한 뒤 다른 시설로 간다. 하나의 대상을 자세히 알기에는 좋지만 기초가 필요할 때마다 끼어들 수 있고, 넓은 분야를 만나는 속도가 늦어진다.

2026년 10월 16일 사용자가 B안을 선택했다. 시작 화면에 과목별 목차, 선수 관계에 따른 추천 순서와 통합 단원을 반영했다. 연구가 이 목차 자체의 우월성을 증명한 것은 아니다. A와 C는 비교했던 대안으로 남긴다.

폭과 깊이를 함께 확보하는 범위

아래는 선택한 구조를 구체화하기 위해 검토한 학습 범위다. 과목 분류와 시설 사례를 같은 층위에 섞지 않는다. 각 과목에는 설명할 수 있어야 할 원리, 직접 풀 수 있어야 할 문제, 선택해서 깊게 들어갈 전문 내용을 따로 표시하는 안을 제안한다.

물리와 공학

힘과 모멘트, 에너지와 일률, 유체, 열전달, 전기 회로, 재료의 변형과 파손. 핵심 식을 조건과 함께 유도하고 간단한 모델을 풀 수준까지. 유한요소법, CFD와 고급 연속체 해석은 관심 분야가 생겼을 때.

화학과 생물

농도와 물질 수지, 산염기와 완충, 반응속도와 평형, 산화환원, 계면과 세정, 부식, 미생물 성장과 제어. 표면 오염과 수처리의 메커니즘을 구분할 수준까지. 센서 반응과 분석화학은 측정 심화에서.

토목과 건축

지반과 물의 이동, 기초와 하중 경로, 배수, 외피와 접합, 단열과 열교, 결로, 재료와 시공 순서, 도면과 시방, 검수와 시운전. 단순 계산과 도면 해석, 하자 가설을 만들 수준까지. 구조 부재의 상세 설계나 지반 수치해석은 별도 전문 과정.

기계와 전기 설비

급배수, 펌프와 여과, 열원과 열교환, 냉동과 히트펌프, 환기와 제습, 모터와 인버터, 전력과 보호, 센서와 제어. 용량, 부분부하, 에너지와 유지관리 조건을 함께 비교할 수준까지.

산업공학과 운영관리

공정과 병목, 변동성과 대기, 작업 배치와 다기능 인력, 재고와 물류, 품질과 재작업, 인간공학, 신뢰성과 보전. 평균값으로 설명되지 않는 실패 조건까지 모델링한다. 복잡한 배치와 일정은 최적화와 시뮬레이션으로 심화한다.

측정, 추론과 경제성

측정 오차, 식별 가능성, 실험 설계, 인과와 진단, 생애주기 비용, 불확실성과 정보의 가치. 그럴듯한 가설을 검증 가능한 주장으로 바꾸는 공통 방법이다. 확률과 미적분을 처음부터 재수강하지 않고 필요한 곳에서 복원한다.

기본 지도는 넓게 보여주되 모든 항목을 똑같은 길이의 수업으로 만들지 않는다. 수처리, 열과 수분, 작업과 변동, 유지관리처럼 여러 판단에 반복 등장하는 부분에 긴 설명과 다양한 문제를 배치한다. 조경, 조명, 음향, 식품 보관, 소방 등의 범위도 위 과목에 연결해 탐색할 수 있어야 한다. 아직 본문이 없는 항목은 학습 가능 표시를 하지 않는다.

매뉴얼을 이해했다는 것을 어떻게 확인할까

매뉴얼은 전체 교육과정의 경계를 정하는 자료로 쓰기보다, 배운 내용에서 빠진 부분을 찾는 시험 재료로 사용한다. 수영장 문서를 읽으려면 적어도 다음 연결이 필요하다.

  • 순환과 여과: 실제 회로 추적 → 압력과 유량 → 입자 포집과 압력 손실 → 역세척과 유량 조건 → 정상 상태와 고장의 구분.
  • 수질: 제품 성분과 농도 단위 → 염소의 화학종과 평형 → pH와 완충 → 반응과 소모 → 채수와 측정 오차 → 소독과 여과가 각각 담당하는 것.
  • 가열과 수위: 열과 물질 수지 → 보일러와 열교환기의 두 회로 → 가열 속도와 손실 → 수위 센서와 밸브 → 지연, 고장과 넘침.
  • 청소와 점검: 오염의 성질과 재료 → 세정의 작용과 조건 → 작업 동작과 순서 → 검수와 재작업 → 예외, 보전과 기록.

최종 확인은 “단어를 아는가”보다 구체적이어야 한다. 회로를 다시 그릴 수 있는가? 이 지침이 성립하는 조건을 설명할 수 있는가? 서로 다른 두 지침이 나오면 무엇을 확인해야 하는가? 장비 고유의 버튼 조작과 설정은 원리만으로 복원할 수 없으므로 실제 모델의 제조사 자료가 필요하다.

NSW Health의 2026년 8월 지침에서 소독, 여과, 수질 측정과 자동 약품 주입의 관계를 대조했다. 특히 ORP 자동 제어를 쓰더라도 소독제 농도의 확인을 별도로 요구한다. 이는 호주 NSW 관할 지침이며 국내 시설의 법정 기준으로 대체하지 않는다.

최신 연구는 마지막의 링크 모음으로 끝내지 않는다

기초 단원 다음에 연구를 읽는 짧은 수업을 붙인다. 순서는 질문 하나 → 논문의 실제 대상과 방법 → 핵심 그림이나 모델 해석 → 기존 방법과의 비교 → 내 조건으로 옮길 때 남는 불확실성이다. 기초를 모두 마쳐야만 연구를 볼 수 있게 막지는 않는다. 이해에 필요한 선수 개념을 연결한다.

2025년 실내 수영장 에너지 전략 연구는 실제 사례를 바탕으로 수온과 공기의 결합을 모델링하고 야간 설정 변경을 수치적으로 비교한다. 읽을 때에는 물 가열 에너지와 공조 에너지를 어디까지 포함했는지, 재가열과 증발을 어떻게 다뤘는지부터 확인한다. 아카이브 판본의 초록, 모델 설명과 전략 비교 부분을 검토했으며, 이 목록에서 수식 전체나 수치 재현을 검증한 것은 아니다.

2020년 미세유체 수질 센서 연구는 최신이라는 이유로 고른 자료는 아니다. 12개 수영장 시료와 기준 측정법을 비교한 실험을 통해 “시료에서 정확했다”와 “현장에 오래 설치해도 정확하다” 사이에 어떤 증거가 더 필요한지 배울 수 있다. 적은 시약 소모량의 계산이 장기간 무정비 운전 실증과 같은 뜻은 아니다.

BOPTEST의 제어 학습 자료는 제어 전략을 건물 시뮬레이션에서 비교할 심화 실습 후보다. 실제 풀의 절감률을 보증하지 않는다. 기초 모델과 제어를 배운 뒤 같은 조건에서 비교하는 방법을 연습하는 데 연결한다.

“최신”과 “최선”을 구분한다. 분야별 쟁점과 검색일, 읽은 범위를 남기고 새 근거가 나오면 연구 수업을 갱신한다. 현재 페이지는 2026년 10월 16일의 수동 조사 결과다. 자동 탐색이나 정기 갱신이 실행 중인 것은 아니다.

다음 확장의 기준

학습량은 한 번에 생성한 페이지 수로 해결되지 않는다. 과목별 기초를 쌓고, 같은 원리를 다른 시스템에서 쓰고, 설명이 실패하는 조건을 배우고, 전문 자료와 최신 연구로 이어지는 경로가 있어야 계속 공부할 수 있다.

새 단원을 추가할 때에는 선수 개념, 충분한 설명, 그림이나 모델, 풀이 예제, 다른 조건의 문제, 지연 복습, 근거와 적용 범위를 함께 확인한다. 모든 주제에 계산을 억지로 넣지는 않는다. 재료나 시공 단원에는 사진과 도면 판독, 운영 단원에는 시간표와 변동 사례가 더 적절할 수 있다.

이번에 다시 쓴 것은 압력과 유량 단원 하나다. 읽기, 그래프 조작, 단계가 줄어드는 문제, 진단 비교, 다른 시설로의 전이, 본문을 가린 복습, 노트와 질문 복사가 실제로 이어진다. 장기 기억과 학습 효과는 아직 검증되지 않았다. 전체 구조는 B안으로 정했다. 다른 수업은 같은 깊이와 학습 흐름으로 다시 작성해야 한다.
